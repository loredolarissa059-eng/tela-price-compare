# Tela Price Compare

Quero criar um sistema para fazer cotações de telas. Quero subir, por exemplo, 3 planilhas Excel: uma do meu concorrente e outras duas dos meus distribuidores, para comparar preços e ver onde posso comprar mais barato. As descrições dos produtos são diferentes entre as planilhas. Quero comparar pelo modelo e pela qualidade da tela, por exemplo, “iPhone 11 OLED”. OLED, Soft OLED e Incell são qualidades de telas. Diamond e Gold são marcas e podem aparecer separadamente. Quero que o menor preço fique destacado em vermelho. Um dos fornecedores trabalha com telas DR, que são uma linha própria dele; quando mostra só “iPhone 11”, é uma tela de outro fabricante. No catálogo desse fornecedor, “Soft Original” é Soft OLED. O concorrente não informa que é FHD, porque essa já é a qualidade de tela que o próprio aparelho utiliza. As planilhas são Excel. Quero também conferir se é possível extrair os produtos deste catálogo: https://meu-pedido-sigma.vercel.app/
